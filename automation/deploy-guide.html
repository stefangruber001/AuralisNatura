Before you start

What you're doing here ~25 minutes

Two jobs: (A) install the automation "engine" inside your Auralis CRM spreadsheet and publish it as a web address, and (B) tell Stripe to call that address whenever someone pays. After this, a payment automatically creates the client's folder, files their intake, and sends the emails — you only approve the report and run the call.

Have these ready • The Auralis CRM spreadsheet open in a browser tab.
• The engine code: open github.com/stefangruber001/AuralisNatura → branch v2-automation → automation/apps-script/Code.gs. (Or just ask me in chat and I'll paste the whole code for you.)
• Your Stripe dashboard login.
Part A · Install the engine in Google

Deploy the Apps Script

1

Open the script editor

Auralis CRM sheet
  1. Open your Auralis CRM spreadsheet.
  2. Top menu → Extensions → Apps Script. A new tab opens with a file called Code.gs.
2

Paste the engine code

Apps Script
  1. Select all existing content in the editor (Ctrl/⌘+A) and delete it.
  2. Open the Code.gs from GitHub (path above), click the Raw button, select all, copy.
  3. Paste it into the Apps Script editor.
  4. Click the 💾 Save icon. Rename the project (top-left, "Untitled project") to Auralis Engine.
Already filled for you: your folder ID, CRM ID, intake form link and Calendar booking link are in the code. You don't need to edit those.
3

Check one setting

Apps Script · top of code

Near the top you'll see CRM_TAB: 'CRM'. Make sure 'CRM' matches the name of the tab in your spreadsheet that holds the columns (Timestamp, Name, Email…). If your tab is named differently, change the text between the quotes to match, then Save.

4

Add the secret webhook token

Apps Script · Project Settings
  1. Left sidebar → ⚙ Project Settings.
  2. Scroll to Script Properties → Add script property.
  3. Property: WEBHOOK_TOKEN
  4. Value: invent a long random string (32+ characters, letters & numbers, no spaces). Example pattern: an_9f3Kq7Lp2Xc8Vb4Nz6Rw1Ty5Hs0Md — make your own and keep a copy; you'll paste it into Stripe in Part B.
  5. Click Save script properties.
Why: Google scripts can't read Stripe's signature header, so this secret token is what proves a request really came from your Stripe. Treat it like a password.
5

Authorise & create the intake trigger

Apps Script · editor
  1. Back in the editor, in the function dropdown (top toolbar) choose setupTriggers.
  2. Click ▶ Run.
  3. A Google permissions dialog appears → Review permissions → choose your account → "Google hasn't verified this app" → Advanced → Go to Auralis Engine (unsafe) → Allow. (This is your own script; it's safe.)
  4. When it finishes you'll see a confirmation. This links the intake form → spreadsheet automation.
Important: the intake Google Form must be set to send responses to this spreadsheet (Form → Responses → Link to Sheets → the Auralis CRM).
6

Publish as a Web App (the address Stripe will call)

Apps Script
  1. Top-right → Deploy → New deployment.
  2. Click the ⚙ gear next to "Select type" → choose Web app.
  3. Description: Stripe webhook
  4. Execute as: Me (your email).
  5. Who has access: Anyone. (Required so Stripe can reach it. It's protected by your secret token.)
  6. Deploy → authorise again if asked → copy the Web app URL (looks like https://script.google.com/macros/s/AKfy…/exec). Keep it for Part B.
Part B · Connect Stripe

Point Stripe at your web app

7

Make sure payments collect name & email

Stripe · Payment Links
  1. Stripe Dashboard → Payment Links → open each of your three product links.
  2. Confirm the checkout collects customer name and email (Stripe collects email by default; enable "Collect customers' names" if it's off).
Why: the automation reads the buyer's name + email from the payment to create their folder and send their welcome email.
8

Add the webhook endpoint

Stripe · Developers
  1. Make sure you're in the same mode as your Payment Links — Test/Sandbox for now (toggle top-right of Stripe).
  2. Go to Developers → Webhooks → Add endpoint (or + Add destination).
  3. Endpoint URL: paste your Web app URL and add ?token= followed by your secret token. The full thing looks like:
https://script.google.com/macros/s/AKfy…/exec?token=YOUR_WEBHOOK_TOKEN

(Replace AKfy… with your real URL and YOUR_WEBHOOK_TOKEN with the exact token from Step 4.)

9

Choose the event & save

Stripe · Webhooks
  1. Select events to listen to → search and tick checkout.session.completed.
  2. Click Add endpoint to save.
10

Test it end-to-end

Stripe → your Sheet
  1. Open one of your Payment Links and complete a test payment (Stripe test card 4242 4242 4242 4242, any future date, any CVC, your own email).
  2. Within a few seconds check your Auralis CRM sheet: a new row should appear with status Paid, a client folder + report Doc linked, and a welcome email in that inbox.
  3. If nothing appears: in Apps Script → Executions (left sidebar) check for errors; and in Stripe → the webhook → recent deliveries confirm it shows 200. A 401 means the token in the URL doesn't match Step 4.
When you're done — send me two things
  1. The Web app URL worked? Just say "deployed ✓" (you don't need to share the URL or token — keep those private).
  2. If you'd like, the report template Doc ID — though I'll create that Doc for you once you approve the Google Drive permission.
Going live later When you're ready to take real payments, switch Stripe to Live mode and repeat Steps 8–9 there (Live mode has its own webhooks). Use the same Web app URL + token.
