Phase 1 · You build · ~45 min

Step-by-step setup

Do these in order. Each step says WHERE to do it and exactly what to click and type. At the end you send Claude four pieces of information.

1

Set your data region to Europe

admin.google.com
  1. Go to admin.google.com and sign in as the admin.
  2. Left menu → Account → Data regions (or search "data region" in the top bar).
  3. Set the region to Europe and Save.

✔ You said this is already done. Good — this keeps client health data in the EU (GDPR).

2

Create the client Drive folders

drive.google.com
  1. Open drive.google.com.
  2. Click + New → New folder, name it exactly Auralis — Clients.
  3. Open that folder, create a subfolder inside it named _TEMPLATE. (Claude will put the report template document in here later.)
  4. Open the Auralis — Clients folder and look at the browser address bar. The folder ID is the long code after /folders/. Copy it somewhere safe.
Example. If the URL is drive.google.com/drive/folders/1A2b3C4d5E6f7G8h, the folder ID is 1A2b3C4d5E6f7G8h.
3

Create the CRM tracking sheet

sheets.google.com
  1. Go to sheets.google.com → Blank spreadsheet.
  2. Rename it (top-left) to Auralis CRM.
  3. In row 1, type these column headers, one per cell (A1 through I1):
Timestamp | Name | Email | Package | Amount | Status | ClientFolder | ReportDoc | Notes

The Status column will move through: Paid → Intake → Drafting → Approved → Delivered → Reviewed.

Copy the Sheet ID from the URL — it's the long code between /d/ and /edit.

4

Build the intake form

forms.google.com
  1. Go to forms.google.com → Blank form. Title it Auralis Natura — Secure Intake.
  2. Add the questions exactly as listed in the companion file automation/INTAKE-FORM.md (Sections A–D, including the red-flag screen and consent boxes). Each section there maps to a "Section" in the form (use Add section).
  3. Top-right Settings tab → turn on Collect email addresses, Limit to 1 response.
  4. Make the consent questions (Section D) Required.
  5. Go to the Responses tab → Link to Sheets → choose your Auralis CRM sheet (this adds an "Intake" tab automatically).
  6. Click Send → 🔗 link, tick Shorten URL, and copy the public form link.
Tip. The full question wording is already written for you in INTAKE-FORM.md — you can copy-paste each question and option straight in.
5

Create the free-call booking page

calendar.google.com
  1. Open calendar.google.com.
  2. Click Create → Appointment schedule.
  3. Title: Free 25-min discovery call. Set duration to 25 minutes.
  4. Set your availability (the protected hours you want to offer).
  5. Under Booked appointment settings: turn Google Meet ON (adds a video link automatically), and add email reminders (e.g. 24 hours + 1 hour before).
  6. Optional: add a couple of intake questions (name, what they'd like help with).
  7. Save, then click Open booking page and copy that booking link.
Step 6 · Send these four things to Claude
  1. Calendar booking link (from Step 5)
  2. Intake form link (from Step 4)
  3. CRM Sheet ID (from Step 3)
  4. "Auralis — Clients" folder ID (from Step 2)

Just paste them into the chat. That's all Claude needs to finish the build.

Phase 2 · Claude builds · you approve

What happens after you send the links

Once Claude has your four items, here's what gets wired up — you don't do any of this, but here's what to expect:

3Connects it to Stripe as a webhookA paid invoice auto-starts the whole client flow
4Loads the EN/DE/ES email templatesThe right email sends itself at each stage
5Gives you the Report Google Doc + Claude drafting workflowYou draft, edit & approve each report
One thing Claude will ask you for in Phase 2 To connect Stripe, you'll create a webhook in your Stripe dashboard pointing to the Apps Script URL Claude gives you. Stripe shows a signing secret — you paste that into Apps Script (never into the website or the repo). Claude will walk you through the exact clicks when we get there. Never share a secret key that starts with sk_ — only the webhook signing secret, and only inside Apps Script.
Once it's live

Your day-to-day, per client

  1. Free call. They booked themselves; you just show up on Meet.
  2. Send payment link. Paste your existing Stripe link for the package they chose.
  3. (Automatic) Payment → folder created, welcome + intake emails sent, CRM row added.
  4. Draft the report. Paste their intake answers into your Claude "Auralis Report Engine" project → review, edit, and approve every word → paste into the report Doc.
  5. (Automatic) One click → PDF rendered, delivery email sent, status updated.
  6. Walk-through call. Run the session on Meet.
  7. (Automatic) A few days later → review-request email goes out.
That's the whole engine. Your protected hours go only to the two things that need a human: approving reports and the calls. Start with this and we automate any remaining bottleneck once you've run your first few clients.
