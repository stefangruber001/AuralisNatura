# Signature

The founder's hand-signed sign-off that closes the About section. It converts a
page of claims into a person taking responsibility for them, which is the point
of the whole section.

```jsx
<Signature role="Gründerin · Auralis Natura — Holistic Health">
  Desiree Gruber
</Signature>
```

One per page, at the end of the About column and nowhere else. `role` carries
the title line beneath the name — keep it factual, and keep it consistent with
the credentials in `MetaList`.
